This folder holds non-runtime files kept for reference and manual testing.

Structure
- original/ — original single-file breakdowns and legacy HTML pages kept for historical reference.
- variants/ — previous iterations of company-card CSS/JS/HTML that are not loaded by the current app.
- manual-tests/ — standalone test pages (e.g., test-company.html) and debug helpers.
- docs/ — historical implementation summaries/status docs superseded by the living README.

Notes
- Nothing in archive/ is imported by the running app. Do not reference these files from production code.
- You can open manual test pages directly in the browser while running the static server for ad‑hoc checks.

Index reference
- Place your legacy Index_old.html in `archive/original/` when ready. It is not used at runtime, but serves as inspiration for the new index shell.
